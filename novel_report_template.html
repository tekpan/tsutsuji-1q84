Search method and source notes
  • Searched __SENTENCES__ sentence units across all 79 narrative chapters in 村上春樹『1Q84』BOOK1–BOOK3, from 1Q84 (全三冊).epub. Covers, contents, and other front matter are excluded. Ruby readings are removed; base characters and original wording are preserved.
  • Each L1 base expression and every descendant L9 surface form in tsutsuji1.1.xml is searched literally, with segmentation dots removed. Matching is case-sensitive and script-sensitive. No unregistered spelling or free paraphrase is generated.
  • Janome 0.5.2 / IPADIC provides token boundaries. Both ends of each match must align with tokens, with one explicit exception: どころか is recognized inside the fused token それどころか. Additional rules distinguish several ambiguous auxiliaries and particles, including う・れる・たい・ない・た・だ・て・で・そう. The full Tsutsuji left/right connection system and semantic senses are not parsed. Lexical uses or a different grammatical sense may remain; some real uses can be missed.
  • “Matching sentence units” counts distinct sentence strings per entry, not occurrences. Repeated identical wording is counted once. Up to the first 10 distinct units are shown. Several occurrences of the same grammar in one sentence still produce one example.
  • Japanese terminal punctuation separates sentence excerpts, including inside dialogue. A final quoted sentence stays with an attached reporting clause. Original quote marks are retained, so an excerpt can begin or end inside a quotation. Final unpunctuated paragraph fragments are retained. Paragraph numbers count all original <p> elements, including blank ones; sentence-unit numbers restart within each paragraph.
  • “No match” means no result under these exact dictionary and morphology rules; it does not prove that the grammar is absent from the novel. Literal L1 spelling counts use the same morphology checks.
  • Meaning labels are the dictionary’s Japanese labels, not translations or confirmed senses of each example. One example may legitimately appear under several overlapping L1 families.
  • Novel text: supplied by the user; author 村上春樹. Dictionary: Suguru Matsuyoshi and Satoshi Sato, © 2008, CC BY-SA 4.0. This offline analysis contains selected source excerpts and uses no external scripts, fonts, or network requests.
